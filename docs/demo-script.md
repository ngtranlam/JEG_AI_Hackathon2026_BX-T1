# Demo Script (Hackathon)

## Goal

Show that one brief turns into two meaningfully different, reviewable variants with visible TRAE-style orchestration.

## Setup

1. Start Redis
2. Start the worker
3. Start the web app

## Live Demo Steps

1. Open the web app home page.
2. Select an example preset (F&B or Skincare).
3. Click "Create project".
4. Call out the generated project id.
5. Click "Enqueue generation".
6. Point at the workflow panel and highlight:
   - Node order
   - Running → completed transitions
   - Per-node logs
7. Scroll to the Variants panel and highlight:
   - Variant A: Emotional Storytelling
   - Variant B: Product-led Demo
   - Selected hook for each variant
   - Script beats aligned to the requested duration

- "This is not a generic prompt-to-video app. We treat content production as a staged workflow."
