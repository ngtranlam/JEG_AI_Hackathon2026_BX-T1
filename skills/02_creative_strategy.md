# Skill 02 — Creative Strategy

## Objective

Generate 2 creative variants that are meaningfully different and useful for A/B testing.

## Required variant structure

Each variant must include:

```json
{
  "variant_id": "A",
  "name": "Emotional Storytelling",
  "angle": "",
  "hypothesis": "",
  "style": "",
  "target_emotion": "",
  "cta_strategy": ""
}
```

## Recommended default variants

For most briefs, use:

```text
Variant A: Emotional Storytelling
Variant B: Product-led Demo
```

## Variant A — Emotional Storytelling

Use when:

```text
The product solves a human pain point.
The audience has a relatable daily struggle.
The brand wants trust and empathy.
```

Structure:

```text
Hook
→ relatable problem
→ product appears as solution
→ emotional benefit
→ CTA
```

## Variant B — Product-led Demo

Use when:

```text
The product benefit is visual.
The audience wants proof quickly.
The brand wants direct conversion.
```

Structure:

```text
Hook
→ product reveal
→ demo steps
→ key benefits
→ CTA
```

## A/B testing hypothesis

Each variant must explain what it tests.

Example:

```text
Variant A hypothesis:
The audience will respond better to relatable workday stress and emotional relief.

Variant B hypothesis:
The audience will respond better to clear product convenience and visual food appeal.
```

## Rules for difference

Variants should differ in:

```text
Hook type
Story arc
Visual direction
Pacing
CTA
Emotional target
```

Do not only change:

```text
Caption
Music
Subtitle color
Small wording
```

## Creative direction generation prompt pattern

Use this structure:

```text
Given the brief, audience, brand tone, product, and compliance constraints,
generate 2 creative directions for short-form video ads.

Each direction must include:
- name
- insight
- concept
- hook style
- visual style
- target emotion
- CTA strategy
- A/B testing hypothesis
- must avoid
```
