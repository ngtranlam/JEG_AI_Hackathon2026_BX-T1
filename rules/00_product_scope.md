# Rule 00 — Product Scope

## Product name

**TRAE AI Video Content Factory**

## Objective

Build a web app and workflow runner that turns a marketing brief and brand kit into **2 publish-ready short-form video variants** for TikTok / Reels / Shorts.

## Challenge focus

This project is for the BX-T1 challenge:

```text
Brief in → 2 publish-ready TikTok/Reels/Shorts variants out
Target duration: 15–30 seconds
Goal: complete under 60 minutes
Core video model: Seedance 2.0
Workflow orchestration: TRAE must be visible
```

## Main product promise

The system must demonstrate:

```text
1. User enters a brief.
2. System generates 2 meaningfully different creative directions.
3. System generates hooks, scripts, storyboards, and Seedance prompts.
4. System generates video clips using Seedance 2.0.
5. System stitches clips into final videos.
6. System adds voiceover, subtitles, cover, title, and caption.
7. System exports both 9:16 and 1:1 outputs.
8. System shows workflow progress and publishable score.
```

## Target user

```text
- Solo creators
- Small content teams
- SME marketing managers
- E-commerce brands
- F&B brands
- Service businesses
```

## Primary use case

Input example:

```text
Brand: GreenBite
Product: Healthy salad delivery
Audience: Office workers 25-35
Tone: fresh, energetic, trustworthy
Platform: TikTok + Reels
Duration: 30s
Claim: Eat healthy without meal prep
Compliance: No fast weight-loss claims
```

Output example:

```text
Variant A: Emotional Storytelling
Variant B: Product-led Demo
```

Each variant includes:

```text
- Final video 9:16
- Final video 1:1
- Cover image
- Title
- Caption
- Hashtags
- Script
- Storyboard
- Seedance prompts
- Evaluation score
```

## Product form

Build a **minimal but professional web app**.

The app does not need user login, billing, dashboard analytics, or complex collaboration features.

Focus on:

```text
- Input clarity
- Workflow visibility
- 2 video outputs shown side by side
- Export buttons
- Editor feedback box
```

## Success definition

The product is successful if a judge can understand within 10 seconds:

```text
This system receives a brief and outputs two ready-to-publish videos.
```
